# persistent_data_structures

Проект по курсу "Современные методы программирования"

# Уточненная формулировка задачи

Реализовать библиотеку со следующими структурами данных в persistent-вариантах:
- Двусвязный список
- Ассоциативный массив (на основе бинарного дерева)
- Бинарное дерево

Язык реализации - Java. Должен быть единый API для всех структур.

# Предполагаемый путь решения задачи

1. Изучить теоретические материалы по теме "Персистентные структуры данных"
2. Найти список алгоритом реализации персистентных структур данных и выбрать наиболее подходящиее для данной задачи
3. Реализовать персистентные реализации предложенного списка структур
4. Проанализировать дополнительные требования, выбрать из них подмножество и реализовать

# Сборка

Для сборки проекта, запуска тестов или генерации документации можно использовать make-файл, находящийся в корне проекта.

Доступные target'ы:

- `build`: запуск сборки проекта. Собранный jar-архив с библиотекой будет находиться в папке *target* 
- `test`: запуск всех unit-тестов, содержащихся в проекте
- `generate-doc`: запуск генерации документации с помощью javadoc. Сгенерированная документация в виде html-документов будет сохранена в папке *target/site/apidocs*.
